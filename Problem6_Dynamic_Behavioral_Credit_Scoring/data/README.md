# Data

This problem consumes the real raw Kaggle `train_data.csv` (per-statement rows, up to 13 chronological statements per customer) to build each customer's full behavioral panel, joined with Problem 1's real champion PD score and Problem 4's real severity tier. Raw CSVs are **not redistributed in this repository** -- download them from the competition page and run this problem's notebooks against your own local copy of the platform folder (after Problem 1's Notebooks 01-05 and Problem 4's Notebooks 26-29 have been run).

Competition: https://www.kaggle.com/competitions/amex-default-prediction
