# Data

This problem consumes the real raw Kaggle `train_data.csv` (per-statement rows), restricted to each customer's first K chronological statements. Raw CSVs are **not redistributed in this repository** -- download them from the competition page and run this problem's Notebooks 34-37 against your own local copy of the platform folder (after Problem 1's Notebooks 01-05 have been run).

Competition: https://www.kaggle.com/competitions/amex-default-prediction
