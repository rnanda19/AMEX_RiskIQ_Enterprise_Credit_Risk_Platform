# Data

This problem consumes real per-customer PD (from Problem 1) and severity tier (from Problem 4) computed on the real Kaggle **American Express Default Prediction** competition dataset. Raw CSVs and the large per-customer `ecl_by_customer.csv` output (tens of MB) are **not redistributed in this repository** -- regenerate them by running Problem 1's and Problem 4's notebooks first, then this problem's Notebooks 30-33.

Competition: https://www.kaggle.com/competitions/amex-default-prediction
