# Data

This problem consumes real per-customer engineered features from Problem 1 (Notebook 03's correlation-filtered D_* columns) on the real Kaggle **American Express Default Prediction** competition dataset. Raw CSVs and the large per-customer `severity_scores_holdout.csv` output (~10MB) are **not redistributed in this repository** -- regenerate them by running Problem 1's notebooks first, then this problem's Notebooks 26-29.

Competition: https://www.kaggle.com/competitions/amex-default-prediction
