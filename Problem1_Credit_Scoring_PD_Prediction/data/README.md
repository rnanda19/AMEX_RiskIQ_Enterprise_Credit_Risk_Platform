# Data

This platform is built on the real Kaggle **American Express Default Prediction** competition dataset. The raw CSVs (tens of gigabytes) are **not redistributed in this repository** -- download them yourself from the competition page and point `01_business_understanding.ipynb`'s `DATA_ROOT` at that folder to reproduce every result in this repository from scratch.

Competition: https://www.kaggle.com/competitions/amex-default-prediction
